# pylibs learning python libraries

Requirements
Python 3.14.7

## Task 2: NumPy arrays and numerical computation

Task 2 demonstrates NumPy-based numerical computation with hourly temperature readings and a simulated household smart-meter example. It covers summary statistics, Celsius-to-Fahrenheit conversion, plotting, hourly energy usage, and estimated tariff costs.

The full documentation, assumptions, interpretation, and instructions for running both examples are available in [TASK_02_DOCUMENTATION.md](Real-world%20use%20of%20python%20libraries/TASK_02_DOCUMENTATION.md).
